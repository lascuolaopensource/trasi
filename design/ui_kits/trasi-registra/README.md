# UI kit — REGISTRA / AGGIORNA

Il registro delle schede, degli eventi e delle opportunità della Casa. Oggi il servizio è NocoDB
(`/nocodb/?casa=<slug>`) e nella Home è dichiarato **non ancora attivo**: il kit mostra sia lo stato
dichiarato sia la forma che avrebbe il registro con i token di Trasi.

Il punto di design: il modulo **non salva**, propone. Il bottone dice «Invia come proposta» e la nota
accanto lo ripete, perché il vincolo V4 (proponi → approva → applica) non è una regola tecnica
nascosta: è quello che succede davvero quando l'operatore premi il bottone.

Il campo «Da dove viene l'informazione» è obbligatorio per principio: nella rete non entrano dati
senza fonte.
